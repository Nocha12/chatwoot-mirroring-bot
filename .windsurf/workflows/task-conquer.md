description: mcp task manager를 사용하여 유저로 부터 받은 requestId를 기반으로 테스크를 순서대로 실행한다.
---

1. mcp task manager를 사용하여 requestId 하위에 있는 모든 테스트 목록을 불러온다.
2. 제일 먼저 해야할 테스크를 판단하고 선택한다.
3. 해당 테스크가 추상적이거나 구체적이지 않을 경우, 우선 테스크를 더 구체화한다.
3.1 구체화된 테스크를 저장 후 다시 테스크를 선택한다.
4. 선택된 테스크를 해결한다.
5. 다시 1.으로 돌아가 테스크를 선택한다.
