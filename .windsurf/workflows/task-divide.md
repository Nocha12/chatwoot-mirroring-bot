---
description: mcp task manager로 부터 작업 목록을 불러와서 최소 작업 단위로 쪼개는 작업
---

1. mcp task manager로 부터 작업 목록을 불러온다.
2. 작업을 최소단위로 잘라 작업하기 쉽도록 만든다.
3. 작업을 분할할때 경로, 파일명, 함수명을 반드시 포함한다.
4. 하위 작업은 쪼개기 전 원래 작업과 같은 임의의 타입을 가져야한다. (없다면 추가)
5. 작업의 순서대로 우선순위를 부여하여 작업의 순서가 꼬이지 않게 방지한다.
6. 더이상 나눌 작업이 없다면 유저에게 그만하라고 알린다.
